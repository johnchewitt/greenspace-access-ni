# Greenspace Access NI

**Understanding Access, Quality & Wellbeing Across Northern Ireland**

A premium interactive explorer for Outscape's proposed **Greenspace Standards Index**
(56 Degree Insight analysis of POMNI 2025) — a companion to the
[Greenspace NI Map](https://out-scape.com/greenspace-ni-map/) that pairs residents'
*perceptions* of their local greenspaces with the objective provision mapping Outscape
already publishes.

## Four experiences

| Mode | What it shows |
|---|---|
| **Explore** | Interactive council choropleth of the index (overall + four themes, % of maximum or index vs NI = 100), national KPI cards, council profiles, live Greenspace NI Map layers |
| **Understand** | How the index is built: POMNI Q14/Q15, scoring, equal-weighted themes, demographic findings, reliability caveats |
| **Compare** | All 11 councils ranked and profiled against the NI average |
| **Perception vs Provision** | *Signature mode* — what residents experience beside what the map shows, on two geographically synchronised maps with published household-proximity indicators |

## Run it

```bash
cd app
npm ci
npm run dev        # development
npm run build      # typecheck + production build → dist/
npm run preview    # serve the production build locally
npm test           # data-contract tests
```

Deployment: pushing to `main` builds and publishes to GitHub Pages via
`.github/workflows/deploy.yml` (enable **Settings → Pages → Source: GitHub Actions** once).

## Stack

React 19 + TypeScript (strict) · Vite · ArcGIS Maps SDK for JavaScript 5.1 (map
components) · Calcite Design System · ECharts · GitHub Pages.

The ArcGIS SDK assets ship with the app, and the council boundaries + all survey values
are bundled locally, so the **core index explorer works even with every external service
unreachable**; Outscape's live layers and the OSM basemap light up when online.

## Data integrity

All survey values come from `src/data/source/*.json`, generated by
`../scripts/extract_data.py` from the interim report and validated (see
`../DATA_EXTRACTION_VERIFICATION.md`). The app never recomputes published values; the
statistical integrity rules in `../GREESPACE_METHODOLOGY.md` §6 bind every view.
