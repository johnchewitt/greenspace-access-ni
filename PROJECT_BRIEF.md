# PROJECT_BRIEF.md — Greenspace Access NI

**Application:** GREENSPACE ACCESS NI
**Subtitle:** *Understanding Access, Quality & Wellbeing Across Northern Ireland*
**Client:** Outscape (Belfast-based outdoor recreation not-for-profit)
**Purpose:** Client demonstration of a premium interactive Greenspace Standards Index
application — a companion to Outscape's existing Greenspace NI Map
(https://out-scape.com/greenspace-ni-map/).

## The proposition

The existing Greenspace NI Map answers *"what greenspace is there, and who lives near
it?"* — objective provision built from 50+ datasets. The POMNI-based Greenspace Standards
Index (56 Degree Insight, interim report v2, Jul 2026) answers *"how do residents
experience their local greenspace?"* — perceived accessibility, quality and benefits from
4,000 survey responses. **Greenspace Access NI demonstrates the value of combining the
two**: perception alongside provision, each kept honest about what it measures.

## Three connected experiences

1. **EXPLORE** — an interactive NI map of the Greenspace Index by geography (local
   authority, postcode area, postcode sector) and by theme, in the report's three formats
   (% of maximum, index vs NI=100, derived decile view), with Outscape's live greenspace /
   trails / access-point / bluespace layers available as context.
2. **UNDERSTAND** — an interactive explanation of the index: the four themes, the Q14/Q15
   survey questions and NI-level response patterns, how scores are built, the demographic
   findings (deprivation, urban/rural, age, sex, visit frequency), and the limitations.
3. **COMPARE** — geographic and demographic comparison views, theme profiles
   (e.g. BT20 vs BT82 vs NI), top-ten theme rankings, and a future-facing **Perception vs
   Provision** mode joining survey scores to the Greenspace NI Map's published
   accessibility indicators where geography is compatible (council level and NI overall).

## What the demo must prove

- Residents' perceptions add a usable planning layer on top of GIS provision measures
  (e.g. rural Access-To index 87 vs urban 107; Fermanagh & Omagh 84 vs Belfast 109).
- The index works at multiple geographies with honest uncertainty handling (n ≥ 30
  threshold, ±8–18pp margins surfaced in-UI).
- Outscape's existing ArcGIS services can power this directly — no data duplication.

## Non-negotiable integrity rules

The six rules in GREESPACE_METHODOLOGY.md §6 bind every view: perception ≠ provision;
interim/proposed status labelled; n ≥ 30 only; uncertainty surfaced; no implied
significance of small differences; published values canonical.

## Key constraints

- **Stack:** React + TypeScript, Vite, ArcGIS Maps SDK for JavaScript 5.1 (map
  components), Calcite Design System, ECharts; GitHub Pages hosting (static, no backend).
- **Geographic data:** verified public services only — ONS Open Geography LAD boundaries
  (live-tested); Outscape's own layer estate (EXISTING_GIS_SERVICES.md). **No licensed NI
  postcode polygons are freely available** — postcode results render as non-choropleth
  visualisations unless/until Outscape licenses boundaries (DATA_SOURCES.md §3).
- **Design:** premium forest-green / emerald / turquoise / warm-gold identity; "Greenspace
  Access NI" branding across app, browser title, navigation, docs, README, exports and
  deployment config; Outscape attribution with official brand assets only where approved.
- **Timeline:** imminent client demonstration — favour the verified, the simple and the
  polished over the speculative.
